# СнабАгент — интерактивный прототип

**Демо:** https://kopotun.github.io/snabagent-demo/

Прототип единой системы снабжения для застройщика типовых домов. Цепочка: норма этапа, заявка бригадира в мессенджере Max, сверка с остатком нормы, согласование перерасхода, сводная потребность и заказ поставщику, приёмка с фото, остатки и перемещения, закрытие этапа с фактическим остатком, материальные затраты по дому.

Всё работает в браузере, без сервера: слева чаты бригадира и руководителя, справа веб-панель снабженца и карточка дома. Состояние демо хранится в браузере, кнопка «Начать заново» его сбрасывает.

Компания, люди, объекты и цены вымышленные. Разбор заявок в прототипе упрощённый (словарь синонимов и правила); в рабочей системе текст и голосовые разбирает языковая модель.

## Запуск локально

```bash
npm install
npm run dev
```
